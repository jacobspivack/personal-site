# jacobspivack.com

Personal site for Jacob Spivack — static HTML/CSS, hosted on GitHub Pages.

## Local preview

```bash
python3 -m http.server 8000
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Deploy

Push to `main`. GitHub Pages serves from the repo root. Custom domain: `jacobspivack.com` (see `CNAME`).
